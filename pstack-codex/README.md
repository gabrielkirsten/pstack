# Codex support for pstack

The [original pstack plugin](../pstack/README.md) lives beside this directory. The Codex skill entries here read the [host notes](CODEX.md) and then the original skills, playbooks, and scripts.

Install the self-contained distribution with `codex plugin add pstack@gbk-plugins` from [Gabriel’s plugin marketplace](https://github.com/gabrielkirsten/gbk-plugins/tree/main/plugins/pstack). Release 0.17.0 packages the complete upstream pstack 0.15.43 tree at `35a90942a7f02e1ebbc2443643179815f2147954`.
